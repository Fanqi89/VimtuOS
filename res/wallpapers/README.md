# res/wallpapers —— 把自己的壁纸放进系统

把你的背景图**直接丢进这个目录**，然后重新构建（`bash build64.sh`），它们就会被写进
系统卷的 **`/Wallpapers/`** 目录，在「设置 → 个性化 → 壁纸」里可以选到、也可以循环切换。

## 支持的格式

`.png` `.jpg` `.jpeg` `.bmp` —— 四个都行：

- PNG / BMP 由 `kernel/img64.cpp` 的解码器直接吃；
- **JPEG 也支持**（`decode_jpeg64`，渐进式/420/422/444 子采样都覆盖，有 `tests/jpeg64_test.py` 守着）。

## 命名与顺序

- 目录内的图按**文件名排序**进卷，设置里的"预设壁纸"按钮就按这个顺序一个一个往下切。
- 想控制顺序就改前缀：`01-sunrise.jpg`、`02-forest.jpg` …
- 文件名里**不要有空格**（VimtuFS2 名字上限 31 字节，路径总长 128 字节）；中文名可以，但建议 ASCII。
- 与内置示例同名（`wall-aurora.png` / `wall-grid.png` / `wall-sunrise.png`）时**以内置为准**。

## 尺寸建议

- 与你的显示分辨率同尺寸最省事（QEMU 默认 1024×768，真机常见 1280×800 / 1920×1080）。
- 更大也可以，壁纸按「填充 / 适应 / 平铺 / 居中」等 6 种模式缩放（设置里可切）。
- 系统卷只有 12 MB 左右，**单张建议 ≤ 1 MB**；放大图（几 MB）会把卷塞满，
  构建脚本会打印 `/Wallpapers` 的总字节数，注意别让它失控。

## 内置示例（不需要你准备）

仓库自带三张代码生成的示例壁纸，同时也放在 `build64/presets/`（由 `tools/make_presets.py` 画）：

| 文件 | 内容 |
|---|---|
| `wall-aurora.png` | 三段渐变 + 暗角（深蓝 → 紫 → 暖粉） |
| `wall-grid.png` | 深灰底 + 细网格 + 右上柔光（低对比工作背景） |
| `wall-sunrise.png` | 暖色天空渐变 + 太阳 + 深色地平线 |

预设头像（6 张，代码画）在系统卷的 **`/Avatars/`** 里，与壁纸分开放 —— 见
`tools/make_presets.py`。
