# 字体许可说明（四个字体面 + 三份许可）

内核嵌入**四个字体面**（`kernel/font.{h,cpp}`，构建期由根目录的
`_otf2ttf.py` / `_subsetsimhei.py` / `_subset_fonts.py` 子集化）：

| 面 | 用途 | 源字体（家族 / 版本） | 协议 | 内核里的产物 |
|----|------|----------------------|------|--------------|
| 0 | 西文 UI（英文/数字/符号） | Noto Sans Regular 2.008 | SIL OFL 1.1 | `build/font_bahnschrift.ttf` |
| 1 | 中文（界面 + GB2312 一级汉字） | Noto Sans SC 2.004-H2（静态字重由官方可变字体 pin `wght=400` 派生） | SIL OFL 1.1 | `build/font_simhei.ttf` |
| 2 | 终端等宽（中英严格 1:2：ASCII 8px = 汉字 16px 的一半） | Sarasa Mono SC 1.0.41（Unhinted） | SIL OFL 1.1 | `build/font_mono.ttf` |
| 3 | 缺字兜底（前三个面都没有、但界面/终端字面量里出现的码点） | GNU Unifont 14.0.01 | GPL-2.0+ with font exception / SIL OFL 1.1（双许可） | `build/font_fallback.ttf` |

**不再使用衬线面**（Noto Serif / Chaparral 已退役并从构建里删除）。

## 三份许可全文（随附要求：仓库里有副本，字体本体不进仓）

- `Fonts/OFL-NotoSans.txt` —— Noto Sans（face 0）的 SIL OFL 1.1 全文。
- `Fonts-open/OFL-NotoSansSC.txt` —— Noto Sans SC（face 1）的 SIL OFL 1.1 全文。
- `Fonts-open/OFL-Sarasa.txt` —— Sarasa Gothic（face 2）的 SIL OFL 1.1 全文。
- `Fonts-open/UNIFONT-LICENSE.txt` —— GNU Unifont（face 3）的 GPL-2.0+（含字体嵌入例外）+ OFL 1.1 双许可说明。

同一份许可另存在 `docs/fonts/` 下（`OFL-NotoSans.txt`、`OFL-NotoSansSC.txt`、`OFL-Sarasa.txt`、
`UNIFONT-LICENSE.txt`）—— 这样"字体本体被 .gitignore 排除"时，许可也不会丢。
文件级清单（文件名/来源 URL/版本/协议/SHA256，含哪些文件参与构建）见根目录 [FONTS.md](../FONTS.md)。

## 分发要求

- 四个面的字体都是**可再分发**的开源字体：随内核/安装介质一起分发没问题。
- OFL 1.1 的要求：不得单独出售字体本体；修改过的字体不得用保留字体名（本项目的子集改名为
  `font_bahnschrift` / `font_simhei` / `font_mono` / `font_fallback`，没有沿用原字体名）。
- Unifont 是 GPL-2.0+（含 font exception）+ OFL 1.1 双许可：本项目按 **OFL 1.1** 使用它
  （也可以按 GPL 分支选择），许可全文随附。
- 源码仓库（GPL-3.0）**不含**字体本体：`Fonts/`、`Fonts-open/` 被 `.gitignore` 排除，
  只放行许可文件；构建脚本在字体缺失时**直接报错退出**（不会静默换字体）。

## 缺字兜底面的码点集合（来源可复现）

face 3 **不全量嵌入** Unifont（12 MB / 57090 字形），只收这份集合：
**扫描 `kernel/*.cpp`、`kernel/*.h`、`user/*.asm` 的字符串字面量**，取"face 0/1/2 的产物都没有"的码点。
本轮实测 = 3 个：`U+2229 ∩`（terminal64.cpp）、`U+6D4F 浏`（drive64/explorer64/kernel64 等）、
`U+6E32 渲`（settings64/taskmgr64）。运行时查询链：

```
给定码点 -> 当前面 -> 中文面（face 1） -> 兜底面（face 3） -> 缺字占位（1px 空心方框 + [FONT64] glyph miss 计数）
```

`kernel/font.cpp` 的 `font_selftest()` 会在启动时打点自检：
`[FONT64] faces=4 …` / `mono ascii=8 cjk=16 ratio=2` / `fallback hit cp=0x2229 face=3` / `selftest PASS mask=…`。
