### ② `content/fetchers/vimtu.c`（1~1.5 天）

- 放在 `third_party/netsurf/netsurf/content/fetchers/vimtu.c`（上游目录里加一个 fetcher，不改别的 fetcher）。
- 只实现 **HTTP/1.1 GET**（+ 可选 HEAD）：`setup()` 解析 URL → 建 socket → `lli`（`nsurl`）；
  `start()` 连 `connect(443/80)`；HTTPS 走 **mbedTLS**（**完全复用 `user/tls/httpsprobe.c` 的 BIO 写法**：
  `mbedtls_ssl_set_bio` + 自写 send/recv 回调，`-EAGAIN` → `WANT_READ/WANT_WRITE`）。
- 回调顺序（NetSurf 的约定，别自己发明）：
  `fetch_vimtu_*` 里发 `FETCH_HEADER`（状态行 + 头）→ `FETCH_DATA`（正文字节，可分块）→
  `FETCH_FINISHED` / `FETCH_ERROR`。
- CA 包直接读 **`/etc/ssl/certs/ca.pem`**（v0.12.4 已随系统卷交付，118 份根证书）。
- 判据：**宿主侧**收到 `GET / HTTP/1.1` + 客人侧 `FETCH_FINISHED` + 正文字节数 == Content-Length；
  再跑一次"错证书站点"必须 `FETCH_ERROR`（不许静默降级）。

### ③ `frontends/vimtu/`（2~3 天，**这就是"浏览器壳子"**）

以 NetSurf 自带的 **`frontends/framebuffer/`** 为模板（最小、无 GUI 工具包依赖），实现这些表：

| 要实现的 | 我们这边对应什么 |
|---|---|
| `gui_table`：`window_create/destroy/invalidate/get_dimensions/set_url/set_title/set_status/set_scroll/…` | `wl_surface_create(15)` + `shm_create(13)`/`shm_map(14)` 拿画布 → `attach(16)/damage(17)/commit(18)` |
| `plot_table`：`rectangle/line/polygon/fill/bitmap/text/clip/flush` | 画到自己的 shm 画布（`fb_*` 风格），圆角/阴影按 `gui_rs` 的 Token |
| `fb_table`（字体） | **内核光栅化 12 号 ABI**（`font64`），CJK 走 `subset` 字库（v0.11.x 已有） |
| `bitmap_table` | 32bpp 位图（libnsbmp/libnsgif/libsvgtiny 解出来的就是它） |
| `utf8` / `search` / `clipboard`（可选） | 先留空实现，别为了它们卡进度 |
| 事件 | `input_poll` + `wl_seat_post(26)` 的鼠标/键盘 → NetSurf 的 `browser_window_*` |

**Edge 风格外壳的 UI 规格（用户原话的落地）**：

- **下载管理**：NetSurf 的 `download_context` → 落 `/Downloads/<文件名>`，进度条 + 取消；

## 5. 坑清单（本轮新踩的，按会咬人排序）

1. **`--whole-archive` 才是"能用"的判据**。静态库默认只拉被引用的成员，"链上了"什么都证明不了。
   它一次抓出 4 类真问题：`fabs/fabsf` 缺对象、libcss `} _ALIGNED;` 的重复符号、
   生成器程序自带 `main` 混进 `.a`、libdom 的 `bindings/` 不在 `src/` 下。
2. **`ls dir/*.c` ≠ `find`**：libcss 的 `src/select` 有 4 层子树，按 `dir/*.c` 只编到 **59/187**，
   而 `cc ok=59 fail=0` 看着像成功 —— **残废的绿**。一律用 `find … -name '*.c'` + `sort -u`。
3. **生成器程序要排除、obj 目录要每次清空**：否则被排除文件上次的 `.o` 还在，照样被打进归档。
4. **libnslog 的 bison 必须带 `api.prefix={filter_}`**（官方按 bison 大版本切换）；
   不带就只有 `yyparse`，而 `filter.c` 调的是 `filter_parse`。
5. **msys2 没有 `llvm-nm`**（只有 `nm.exe`）；符号数判据要匹配 `^[0-9a-f]+ [TDBR] `。
6. **静态 musl 程序要自写 `_start`**（musl 的 crt1.o 有 `lea _DYNAMIC(%rip)`，在 4 GiB+ 的静态非 PIE
   映像里无处解析 → 产物只剩 2 KB 空壳）。样例：`user/tls/httpsprobe.c`、`user/netsurf/smoke.c`。
7. **大映像必须链接在 `0x100090000`**（= `USER64_MMAP_VA64`）：内核 mode-2 装载算
   `base = find_free(USER64_MMAP_VA64, span) - min_vaddr`，基址不等于它就 `base != 0`、绝对地址全错位。
8. **内核启动期跑用户程序只能用真进程路径**（`app64_run_any64` 在合成器活着时会
   `[ELF64] reject reason=busy`）。
9. **QEMU `sendkey` 在 1 fps GUI 下丢字/吞长命令**：所有验收一律"夹具卷开关 + 读串口"，不发键盘
   （除非就是要按回车进桌面，且按键后**必须读回证据**再继续）。

## 6. 关键机制与接口速查（写浏览器时会反复用）

### 6.1 内核 socket / TLS（ring3 可用）
- `socket(41) / connect(42) / sendto(44) / recvfrom(45) / sendmsg(46) / recvmsg(47) / close(3) / poll(7)`；
- `-EAGAIN` = 超时（只有 FIN/RST 才返回 0）；`poll` 看得见 socket（`sock64_ready64`）；
- mbedTLS：`mbedtls_ssl_set_bio(ssl, &bio, bio_send, bio_recv, NULL)`，BIO 回调里
  `send/recv`，`-EAGAIN → MBEDTLS_ERR_SSL_WANT_WRITE/READ`。**完整样例见 `user/tls/httpsprobe.c`**。

### 6.2 画布 / 窗口（ring3）
`shm_create(13)` → `shm_map(14)`（拿到像素）→ `wl_surface_create(15)` → `attach(16)` /
`damage(17)` / `commit(18)`；窗口装饰 `wl_surface_set_decor(28)`、标题 `wl_surface_title(29)`、
控制 `wl_surface_ctl(30)`；`input_poll` + `wl_seat_post(26)` 收回输入。
**样例：`user/viewer/viewer.c`（图片查看器，最接近"浏览器外壳"的现有骨架）+ `user/lib/wl.c`。**

### 6.3 字体
内核光栅化 12 号 ABI（`font64`）；CJK 走构建期子集（`build/font_*.ttf`）；
`user/lib/font64.c` 是 ring3 版本的同一套实现（可参考它的度量）。

## 10. 纪律（全部来自本仓血账，不许破例）

- 结论必须有**串口打点 / 像素判据 / 宿主侧独立解析**三者之一；拿不到就写 `UNVERIFIED`。
- **"部分绿"不许冒充"全绿"**；判据与事实不符时先修脚本，**但不许放宽强度**。
- 长跑/回归一律串行（8 GB 宿主）；收尾必须 `Get-Process qemu-system-x86_64` = 0、`git status --short` 空。
- `PowerShell` 内联 `py -3 -c` 带中文/引号极易挂 → **一律写 `.py` 文件**。
- `Edit` 工具行号极易错位 → 改前必须 fresh `Read`；批量改优先写 python 按**唯一字面串**替换并 `assert count==1`。
